## Building

**[quelltest](https://quelltest.com)** — open-source Python CLI that reads your code as an AST, finds the guard clauses nobody tested, and writes a test that fails before it writes the fix that makes it pass. No LLM key required for the core engine. 11,000+ downloads, 16 releases, no paid tier.

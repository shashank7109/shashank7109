## building

**quelltest** — an open-source Python CLI that reads your code as an AST, finds the guard clauses nobody tested, and writes a test that fails before it writes the fix that makes it pass. No LLM key required for the core engine. 11,000+ downloads, 16 releases, no paid tier.
[quelltest.com](https://quelltest.com)

**Lekha** — meeting audio in, searchable transcript and structured minutes out, with a cloned voice for playback. Speech-to-text with speaker diarisation and automatic action-item extraction.
[lekha.shashankbindal.me](https://lekha.shashankbindal.me)

**Bhagavad Gita Platform** — a certification platform built for ISKCON, with chapter-gated quizzes over an 18-chapter ingestion pipeline and an ontology-driven classifier that cut Bedrock token costs by roughly a third.
[gitaforyouth.com](https://gitaforyouth.com)

**AlertyAI** — say a task out loud, get it scheduled in under two seconds. Flutter and Kotlin on Android, Next.js on web, Sarvam AI underneath.
[alertyai.com](https://alertyai.com)
